## FEATURE BEHAVIOR

### SMS Import Path
```
User receives SMS
    ↓
App shows in review queue
    ↓
User confirms import
    ↓
Transaction created with:
  - note = Full SMS text ✅
  - merchantId = Linked merchant
    ↓
Recent Transactions shows SMS text
```

### Display Priority
```
1. Note (SMS text)          ← Highest priority
2. Merchant nickName
3. Merchant name
4. Transaction type
5. "Unknown"                ← Fallback
```
